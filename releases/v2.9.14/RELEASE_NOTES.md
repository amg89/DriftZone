# Drift Zone v2.9.14

## What's in this release (2025-02-16)

- **Device Type is now free text** — Settings → Station editor, type whatever you want (e.g. "Pool Table", "Racing SIM", "VR Booth"). Autocomplete suggests types you've already used, but nothing is restricted to a fixed list anymore.
- **NEW: Shift breakdown expanded** — both the live open shift card and closed shift history now show Gaming revenue broken down **per device type** (e.g. PS5 vs SIM side by side), not just one combined Gaming total. Same visual style as the existing Payment Breakdown section.

## Upload instructions

1. Create `releases/v2.9.14/` in your GitHub repo
2. Add `drift-zone.html` into that folder
3. Commit: `Release v2.9.14 — free text device type + shift gaming-by-device breakdown`
