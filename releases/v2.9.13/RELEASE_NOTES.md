# Drift Zone v2.9.13

## What's in this release (2025-02-15)

- **NEW: Device Type per station** — set each station's device type (PS5, PS4, PS3, Xbox, SIM, PC, Other) in Settings → Station editor.
- **NEW: Device filter in Sessions tab** — view only PS5 sessions, only SIM sessions, etc, alongside the existing date range filter.
- Session list (both live and closed) now shows a device badge on every row.
- Existing sessions from before this update default to **PS5** for the device badge/filter — go to Settings and adjust each station's Device Type if that's not accurate for your setup (e.g. if you have a racing SIM rig).

## How to use it

1. Settings → find your stations → set each one's **Device Type**
2. Sessions tab → new **Device** dropdown next to the date filters → pick a type to filter the list

## Upload instructions

1. Create `releases/v2.9.13/` in your GitHub repo
2. Add `drift-zone.html` into that folder
3. Commit: `Release v2.9.13 — add device type filter to Sessions tab`
